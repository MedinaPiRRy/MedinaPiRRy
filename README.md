- 💳 **Payments:** Stripe checkout with server-computed prices and signed, idempotent webhooks.
- 🗄️ **Data:** relational and NoSQL design (PostgreSQL, SQL Server, SQLite, MongoDB), versioned migrations, and SQL, Excel and Power BI automation.
- 🧪 **Testing:** unit and integration tests (xUnit, Moq, Vitest, Postman), including tests that throw hostile input at every handler.
- 🖥️ **Desktop and web:** Electron apps with a typed main/renderer contract, and server-rendered Angular and Next.js apps.
